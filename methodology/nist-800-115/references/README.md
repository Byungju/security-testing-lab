# NIST SP 800-115 참고 자료

이 디렉터리는 NIST SP 800-115 학습 및 정리 과정에서 참조하는 원본 자료 정보를 기록한다.
문서의 내용을 옮겨 적기 위한 공간이 아니라, 학습의 근거가 되는 원본 문서를 추적하기 위한 공간이다.

## 원본 문서 정보

| 항목 | 내용 |
| --- | --- |
| 문서명 | Technical Guide to Information Security Testing and Assessment |
| 발행 기관 | NIST (National Institute of Standards and Technology) |
| 발행일 | September 2008 |
| 문서 식별자 | NIST Special Publication 800-115 (NIST SP 800-115) |
| 공식 문서 페이지 | https://csrc.nist.gov/pubs/sp/800/115/final |
| DOI | https://doi.org/10.6028/NIST.SP.800-115 |
| 원본 파일(PDF) | https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-115.pdf |

## 참고 원칙

- 본 프로젝트의 NIST SP 800-115 학습과 정리는 위 원본 문서를 참조한다.
- PDF 원본 파일은 이 저장소에 포함하지 않으며, 필요한 경우 위 공식 링크를 통해 확인한다.
- 원문을 그대로 복사하지 않고, 학습한 내용을 재구성하여 정리한다.
