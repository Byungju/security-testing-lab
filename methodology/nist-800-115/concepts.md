# NIST SP 800-115 핵심 개념

이 문서는 NIST SP 800-115를 학습하면서 이해한 핵심 개념을 정리한 것이다.
세부 프로세스와 테스트 기법은 이후 학습 단계에서 별도로 다룬다.

## NIST SP 800-115란 무엇인가

NIST SP 800-115는 미국 국립표준기술연구소(NIST)가 발행한 정보 보안 테스트 및 평가(Information Security Testing and Assessment) 가이드이다.
조직이 정보 시스템의 보안 상태를 테스트하고 평가할 때 참고할 수 있는 공통된 관점과 절차를 제시한다.

## 문서의 목적

이 문서의 목적은 보안 테스트와 평가를 일관된 방식으로 수행할 수 있도록 기본 개념과 접근 방법을 정리하는 데 있다.
특정 제품이나 도구 사용법을 설명하기보다, 보안 테스트를 어떤 관점에서 바라보고 수행해야 하는지에 대한 기준을 제공한다.

## Security Testing의 기본 개념

Security Testing(보안 테스트)은 정보 시스템이 보안 요구사항과 기대한 보안 수준을 충족하는지 확인하는 활동이다.
시스템을 실제로 점검하고 검증함으로써, 문서상의 설정이 아니라 실제 동작과 상태가 어떠한지를 확인하는 데 초점을 둔다.

## Security Testing과 Security Assessment의 관계

Security Testing은 더 넓은 개념인 Security Assessment(보안 평가)의 일부로 이해할 수 있다.
보안 평가는 조직의 보안 상태를 종합적으로 판단하는 과정이며, 보안 테스트는 그 판단에 필요한 근거를 실제 점검과 검증을 통해 확보하는 활동에 해당한다.
즉, 테스트는 평가를 구성하는 한 요소이며, 평가는 테스트 결과를 포함해 더 넓은 맥락에서 보안 상태를 해석한다.

## 단순한 취약점 찾기가 아니다

Security Testing은 취약점을 찾아내는 것만을 의미하지 않는다.
취약점 발견은 테스트를 통해 얻을 수 있는 결과 중 하나일 뿐이며, 보안 테스트는 시스템이 보안 요구사항을 어느 정도 충족하는지 확인하고, 그 결과를 바탕으로 보안 상태를 판단하며, 이후 개선으로 이어질 수 있도록 근거를 제공하는 활동이다.
따라서 발견한 취약점의 개수보다, 무엇을 어떤 기준으로 확인했고 그 결과가 무엇을 의미하는지가 중요하다.

## NIST SP 800-115의 범위와 한계

NIST SP 800-115는 보안 테스트와 평가를 위한 일반적인 지침을 제공하지만, 모든 환경과 상황에 그대로 적용되는 구체적인 절차를 규정하지는 않는다.
따라서 조직의 환경과 목적에 맞게 해석하고 조정해서 적용해야 한다.
또한 특정 도구나 기술의 사용법을 정하는 문서가 아니며, 보안 테스트 자체가 시스템의 모든 보안 문제를 완전히 찾아낸다고 보장하지도 않는다.

## Security Testing을 바라보는 기본적인 흐름

NIST SP 800-115는 보안 테스트를 한 번의 점검으로 끝나는 활동이 아니라, 계획하고, 수행하고, 결과를 분석하여 후속 조치로 연결하는 일련의 흐름으로 바라본다.
이 흐름의 세부 단계와 각 단계의 구체적인 내용은 이후 학습에서 다룬다.
