# NIST SP 800-115

## 무엇인가

NIST SP 800-115는 미국 국립표준기술연구소(NIST)가 발행한
정보 보안 테스트 및 평가(Information Security Testing and Assessment) 가이드이다.
보안 테스트와 평가를 수행하는 절차와 기법을 다룬다.

## 이 프로젝트에서 학습하는 이유

제품 보안 테스트와 연구소 CERT의 보안 테스트 프로세스를 정리하기 위한
기반 표준으로 삼기 위해 학습한다.

## 앞으로 학습할 내용

- 문서의 목적과 범위
- 보안 테스트 및 평가 프로세스
- 테스트 기법
- 실무 적용 방안

각 항목의 상세 내용은 학습이 진행되면서 단계적으로 추가한다.
