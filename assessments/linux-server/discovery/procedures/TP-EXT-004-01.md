# TP-EXT-004-01 Application and Version Identification (TCP) Procedure

## Test Procedure ID

TP-EXT-004-01

## Related Objective

DO-EXT-004 Application and Version Identification

## Related Test Case

TC-EXT-004-01 Application and Version Identification (TCP)

- 연결 관계: DO-EXT-004 → TC-EXT-004-01 → TP-EXT-004-01.

## Title

Application and Version Identification (TCP) Procedure

## Purpose

- DO-EXT-003에서 식별된 서비스 포트에 대해 애플리케이션/버전 후보를 식별하는 수행 절차를 정의한다.
- 식별 결과와 원본 Evidence를 남겨 Actual Result / Assessment Result로 이어지게 한다.

## Scope

- 포함: 지정 포트에 대한 애플리케이션/버전 식별, Evidence 기록.
- 제외: 취약점/구성 평가, 포트 스캔, 서비스 종류 식별, UDP.

## Preconditions

- 대상이 승인된 평가 범위에 포함되어 있어야 한다.
- DO-EXT-003의 포트-서비스 매핑이 있어야 한다.
- 식별 대상 포트가 Configuration에 명시되어 있어야 한다.
- 사용할 도구(nmap)와 필요한 권한이 확보되어 있어야 한다.
- Evidence를 저장할 위치와 형식이 준비되어 있어야 한다.

## Procedure Steps

| Step | Action | Observation | Evidence |
| --- | --- | --- | --- |
| Step 1 | Preconditions, Target, Assessment Perspective를 확인한다. | 대상 주소, 평가 위치, 승인 상태. | 대상 주소, 평가 위치, 승인 참조. |
| Step 2 | 식별 대상 포트 목록을 확인한다. | 대상 포트(DO-EXT-003 서비스 포트). | 포트 목록. |
| Step 3 | nmap -sV --version-light로 애플리케이션/버전 식별을 수행한다. | 포트별 애플리케이션/버전 후보. | 원본 출력, 사용 옵션/도구, 시각. |
| Step 4 | 식별 Observation을 수집하고 신뢰 수준을 구분한다. | 포트-애플리케이션/버전, 확신/추정/미확인. | 원본 결과. |
| Step 5 | Raw Evidence를 저장하고 완료 조건을 확인한다. | 저장/종료 여부. | Evidence 목록, 종료 판단. |

- 대상 포트는 Configuration의 값만 사용하며, Runner가 임의로 추가하지 않는다.

## Observation Points

- 포트별 애플리케이션과 버전 후보(확인/추정/미확인).
- Tool이 버전을 확정하지 못한 경우(예: tcpwrapped, `?`) 그대로 기록.
- 실행 오류(scan error / timeout / execution error).

- 버전 추정을 확정 사실로 취급하지 않는다.
- 애플리케이션/버전 식별을 취약점 판단으로 확대하지 않는다.

## Evidence Collection

| Step | Evidence |
| --- | --- |
| Step 1 | 대상 주소, 평가 위치, 승인 참조, 시각. |
| Step 2 | 대상 포트 목록. |
| Step 3 | 사용 도구/옵션, 포트별 애플리케이션/버전, 시각, 원본 출력. |
| Step 4 | 포트-애플리케이션/버전 정리와 신뢰 수준. |
| Step 5 | Evidence 목록, 종료 판단. |

## Expected Observation

- 지정된 각 포트의 애플리케이션/버전 후보가 기록된다(또는 미확인/추정으로 기록된다).
- 사용 방식/도구/옵션/시각과 원본 Evidence가 남는다.
- 서비스 종류(DO-EXT-003)와 애플리케이션/버전(DO-EXT-004)이 구분되어 기록된다.

## Completion Criteria

- 지정된 포트에 대한 애플리케이션/버전 식별과 Evidence 기록을 완료했다.
- 다음 중 하나에 해당하면 즉시 종료하고 기록한다.
  - 대상/범위가 승인 범위를 벗어남.
  - 예상치 못한 부작용이나 승인되지 않은 영향이 관찰됨.

## Notes

- 이 Procedure는 결과를 미리 판단하지 않는다.
- 대상 포트는 DO-EXT-003 결과(서비스 포트)를 사용한다.
- 참고: `../objectives.md`의 DO-EXT-004, `../testcases/TC-EXT-004-01.md`, 프로젝트 공통 Tool Catalog(`tools/network/nmap.md`).
